# Diesel Junk Removal website

A clean, mobile-friendly website preview for Diesel Junk Removal, Quitman, Arkansas.

## Preview
The site is static HTML/CSS. To publish it with GitHub Pages: open **Settings → Pages**, choose **Deploy from a branch**, select **main / (root)**, and save.
